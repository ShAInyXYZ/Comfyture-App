Run it your way

The same code on your own GPU or on Comfy Cloud. Only where the models live changes.

Comfy Cloud

No GPU needed

You need a Comfy API key and a paid Comfy Cloud plan. Cloud has the models.

git clone <this repo> comfyture && cd comfyture
npm install
echo "COMFY_API_KEY=comfyui-..." > .env
npm start          # http://127.0.0.1:5177
Your GPU

Everything local

A recent ComfyUI with the models, and the official Comfy API v2 proxy next to it.

pip install comfy-api-proxy
comfy-api-proxy run      # Comfy API v2 on 127.0.0.1:8189
npm start              # http://127.0.0.1:5177

Try it without either

The live demo is the app as static files: presets and takes play, and every prompt and workflow is there. Rolling is off. npm run dev starts the app with tiny stand-in workflows, so you can work on the interface without a GPU or credits.

Questions

Is it free?

The code is MIT licensed and the models are open weights, so running it on your own GPU costs only your hardware. Comfy Cloud needs an API key and a paid Comfy Cloud plan, and the Claude writers are billed in Comfy credits through Comfy Router. Gemma 4 runs inside ComfyUI if you want everything open.

What do I need to run it locally?

Node.js 22.18 or newer, a recent ComfyUI with the models from the README (a script fetches them), and the Comfy API v2 proxy. Accept the model terms on the Lightricks pages before downloading.

Can I make my own presets?

Yes. A preset is a folder with a readable preset.json (and a poster and preview if you want them on the shelf). The 28 that ship are all made this way.

Does the video have sound?

Yes. LTX-2.5 generates the picture and the audio together: the whoosh of a zoom, the crackle of fire, a line of dialogue with lip sync. Cut adds music, effects and voice tracks on top.

Can I try it without a server?

The live demo is the app as static files with the presets, sample photos and a take log. Everything plays; rolling is off. Run npm run demo-site to build your own copy for any static host.

Is it affiliated with ComfyUI?

No. Comfyture is an independent open-source project built on the Comfy Developer Platform. It borrows ComfyUI’s yellow as a nod and does not use its logo.
